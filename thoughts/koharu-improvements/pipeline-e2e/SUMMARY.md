# End-to-end koharu pipeline gallery — curated

Generated by `backend/scripts/visualize_e2e_pipeline.py`. Each page directory contains 11 per-stage artefacts (original → detect → mask → OCR crops → LaMa inpaint → batched LLM translation → final composite) plus `stats.json` with timings and OCR/translate samples.

## How to regenerate / add new manga pages

```bash
cd backend
# explicit image(s) — point this at anything you downloaded
uv run python scripts/visualize_e2e_pipeline.py /path/to/page1.jpg /path/to/page2.png

# all flags:
uv run python scripts/visualize_e2e_pipeline.py --help

# aggregate analysis across the whole gallery
uv run python scripts/gallery_analysis.py   # writes gallery-analysis.md

# refit only the final composite (fast iteration on font/layout)
uv run python scripts/refit_final_composites.py
```
